① 服务器：三级权限

困难版不使用门户。服务器终端就是整个调查界面：访客 → su（admin）→ sudo（root）。

命令

ls / dir　cat / type / open　cd　pwd　su <口令>　sudo <口令>　decrypt <文件> <密钥>　status　whoami　last　uptime　verify <码>　clear

调查链（按顺序）

1. cat README → 时间戳规则 + 权限说明

2. cat /etc/config → V2_BUILD_TS=1730073600 / LEGACY_BUILD_TS=1723680000

3. cat /etc/security/pwpolicy → 口令 = 公司名拼音 + 构建日期

4. su jianganyiliao20241028 → 拿到 admin

5. cat /var/mail/admin → 邮件重申「日期字段一律填公告日」

6. cat /home/zhouming/.ssh/id_rsa → 尾部注释 # unlock: <工号>-<次数>

7. sudo 0471-6 → 工号 0471 + 第 6 次 → root

8. cat /srv/clinical/roster.txt → 承者簿（印 3 1 4 1 5 9，第 7 行 2024-11-18）

⑤ 常见卡点

时间戳怎么转日期？1 天 = 86400 秒；2024-01-01 是 1704067200，往后数。也可以查在线转换。

找不到 .ssh？要先 su 到 admin，权限不够会提示「需要 admin」。

sudo 报错？口令是 0471-6（工号-次数），不是 admin 口令。

verify 说没勘察痕迹？说明没读过 /root/verify.txt，先去读。

终端刷不出来？先等节点连接动画跑完（约 4 秒）。

困难版不改变剧情与结局，只改「获取线索的方式」：全程命令行探案与取证。

② 玩法：靠「搜」解锁

在检索框里输入关键词，命中才会出现条目，同时进度 +1。

同一个词重复搜不算。进度看的是「搜过多少个不同的词」，不是条数。

层级越高，能搜的词越多。到了新层级，系统会在顶部提示新开放的词。

# 江安医药员工失踪事件 · 网页 ARG

一个纯前端的网页解谜游戏（Alternate Reality Game）。

你是一名刚毕业的学生。入职前夜，你开始调查舅舅的失踪——两年了，家里人说他去了外地，你不信。
顺着一个匿名论坛、一家医药公司的官网、一套老旧的内部系统，你一点点往下查。
越查越发现，这家公司藏着一个用「临床试验」包装起来的秘密。

**▶ 在线游玩：<https://dashuai-web.github.io/jiang-an-medical-site/start.html>**

---

## 玩法

进入选择页，选一个难度：

| 难度 | 说明 |
|---|---|
| **普通版** | 顺着官网、匿名论坛与内网检索推进，提示完整，按图索骥即可。 |
| **困难版**（BETA） | OSINT 画像、旧电脑取证、服务器命令行渗透、摩斯电码、404 藏线索……提示极少，全程自己找。 |

> 建议先玩普通版。困难版仍在测试，可能不稳定。

---

## 内容

- 37 个页面，纯静态 HTML / CSS / JS，**无框架、无后端、无需构建**
- 双难度分支，共享同一套剧情与结局
- 三条结局线 + 一条隐藏支线（暗网镜像）
- 内置来源校验、反调试，关键记录运行时解密
- 全站移动端适配
